# Random Task Generator

**Автор:** Баркин Роман
**Дата сдачи** 08.05.2026

## Описание
Графическое приложение для генерации случайных задач.  
Полезно для тех, кто не может выбрать, чем заняться: генератор предлагает случайную задачу из списка (учёба, спорт, работа).  
Ведётся история сгенерированных задач, есть фильтр по типу, возможность добавлять свои задачи.  
История и список задач сохраняются в JSON-файл.

## Использование
1. Запустите `main.py`
2. Нажмите «Сгенерировать задачу» — появится случайная задача.
3. Выберите фильтр, чтобы генерировать задачи только определённого типа.
4. История отображается ниже.
5. Кнопка «Добавить новую задачу» позволяет расширить список (проверка на пустую строку и корректный тип).
6. «Очистить историю» — удаляет историю, но не задачи.

## Примеры (тесты)
- Генерация без фильтра: появляется любая из 6 предустановленных задач.
- Фильтр «спорт»: генерирует только «Сделать зарядку» или «Пробежка на месте».
- Добавление задачи «Помыть посуда» с типом «работа» — получим предупреждение (тип должен быть учёба/спорт/работа).
- Добавление пустой задачи — ошибка.
- После генерации нескольких задач история показывает их в обратном порядке.
